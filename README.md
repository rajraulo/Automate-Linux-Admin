Automation of Traffic switchover 
================================
1. This project is an automation of routing the traffic from Production/Live Servers to Disaster Recovery Servers and vice versa in a regular interval of time.<br>
2. Automation of Traffic switchover from DR to Production and vice versa.<br>
3. A set of DNS changes are made using Ansible Roles.<br>
4. Triggering an Action executes the workflow, it will automatically changes the traffic by changing the IPs.
